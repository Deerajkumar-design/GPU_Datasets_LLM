# Manual Review Package

This package contains the 19 `AMBIGUOUS_REVIEW_REQUIRED` Experiment D cases.

Files:

- `manual_review_19_cases.md`: combined human-readable packet.
- `manual_review_19_cases.json`: machine-readable packet with the same cases.
- `NN_<instance_id>.md`: one file per case.

No adjudication has been applied. Raw model answers and gold answers are copied unchanged from the frozen grading outputs and dataset metadata.
